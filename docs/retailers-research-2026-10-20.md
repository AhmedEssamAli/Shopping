# Online grocery and general retailers serving New Cairo / 5th Settlement — integration map

Research date: 2026-10-20. Probes run with curl from a cloud machine (US egress, via the session proxy, TLS verified) — max 3 requests per site. "Fact (probe)" = observed in our own request. "Fact (src)" = stated by the cited URL (third-party or self-reported, not independently checked). "Unknown" = not verified. A 403/challenge from a cloud IP does not prove the site blocks a home browser in Egypt.

Already integrated in shopper (not re-probed unless noted): Gourmet Egypt, Seoudi, Spinneys Egypt (Magento GraphQL); talabat shops (talabat Mart, Carrefour, Spinneys, Metro, Lulu, Zaher Dairy, The Grove, Zidan); Amazon.eg and noon (home Chrome); Instashop (Mahmoud ElFar shop, rendered page).
